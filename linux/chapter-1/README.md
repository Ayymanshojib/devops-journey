# Chapter 1 – Terminal Navigation

## Goal
Learn how to navigate Linux like a DevOps engineer.

## What I Learned
- Terminal basics
- Linux file system
- Root (`/`) and Home (`~`)
- Absolute vs Relative paths
- Navigation shortcuts

## Commands Practiced
- `pwd`
- `ls`
- `ls -l`
- `ls -la`
- `cd`
- `cd ..`
- `cd ~`
- `cd /`
- `cd -`
- `history`
- `clear`

## Practice
- Navigated between folders
- Used absolute and relative paths
- Used command history
- Used Tab auto-completion

## Interview Notes
- `pwd` = Print Working Directory
- `cd -` returns to the previous directory.
